# 웹 페이지 제작 실습

HTML과 CSS 기초를 소개 페이지, 기업형 웹 화면, 모바일 웹과 정보 탐색 과제로 적용한 기록입니다.

## 반응형 웹 — rwd·jeju

| 작업 | 결과물 | 코드 |
| --- | --- | --- |
| rwd | 요안도라 소개와 사진을 배치한 페이지 | [index.html](https://github.com/seung-gwan/rwd/blob/main/index.html) · [CSS](https://github.com/seung-gwan/rwd/blob/main/common.css) |
| jeju | 요안도라의 숙소·객실 소개 페이지 | [저장소](https://github.com/seung-gwan/jeju) · [index.html](https://github.com/seung-gwan/jeju/blob/main/index.html) |

같은 소재를 다룬 웹 레이아웃 실습입니다. 두 저장소의 스타일 파일에는 각각 3개의 `@media` 규칙이 있습니다.
화면 크기에 따라 내용을 배치하는 방법과 제목·메뉴·본문·이미지의 구성을 공부했습니다.

공지사항에는 목록과 검색 입력 화면이 있습니다. HTML/CSS로 만든 정적 화면을 소개하는 학습 기록입니다.

## 모바일 웹 — mobile

[저장소](https://github.com/seung-gwan/mobile) · [index.html](https://github.com/seung-gwan/mobile/blob/main/index.html)

모바일 웹의 헤더와 내비게이션, 본문 구성을 실습했습니다.
메뉴 라벨 클릭에 따라 `#toggle_gnb`를 `slideToggle()`로 열고 닫는 jQuery 코드가 있습니다.

모바일 앱 대신 브라우저에서 여는 HTML/CSS/JavaScript 실습 페이지입니다.

## 정보 탐색 웹 과제 — Homework

[저장소](https://github.com/seung-gwan/Homework) · [웹 파일 목록](https://github.com/seung-gwan/Homework/tree/main/ex02/src/main/WebContent)

메인 페이지의 제목은 **Apple Tree**입니다. 사용자가 지역과 정보 분야를 선택해 관련 페이지로 이동하는 구조입니다.
부산·대구·광주·서울의 분야별 페이지 등 HTML 파일 33개가 저장되어 있습니다.
메인에서는 Bootstrap 스크립트를 불러오는 구성을 확인할 수 있습니다.

이 과제에서는 여러 HTML 문서 사이의 연결과 정보를 분류해 보여주는 화면 구성을 다뤘습니다.

## 기록 범위

수업·학습용 예제와 레이아웃 작업을 모은 기록입니다. 제공된 이미지·예제 디자인을 사용한 부분을 포함합니다.
이번 정리에서는 저장된 소스와 페이지 구성을 확인했으며, 모든 화면과 외부 링크의 동작을 새로 검증하지 않았습니다.
