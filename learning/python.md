# Python — 문자열과 자료구조 실습

## 1. 문자 코드 변환

[`character_shift.py`](../examples/python/character_shift.py)

문자열을 순회하며 `ord()`로 문자 코드를 얻고 1을 더한 뒤 `chr()`로 다시 문자로 바꾸는 실습입니다.
반대로 1을 빼는 과정을 통해 원래 문자열로 돌아오는 흐름을 확인합니다.
문자와 숫자의 변환, 리스트, 반복문, 입력과 출력을 다룹니다.

```sh
python examples/python/character_shift.py
```

예: 첫 입력 `ABC`, 두 번째 입력 `BCD` → 변환 결과 `BCD`, 복원 결과 `ABC`.

단순한 문자 이동 규칙을 관찰하는 학습 예제이며 실제 정보 보호용 암호화 기능으로 소개하지 않습니다.
Unicode 범위 끝의 문자와 입력 오류를 처리하는 부분은 추가 학습 과제입니다.

## 2. 이진 탐색 트리

[`binary_search_tree.py`](../examples/python/binary_search_tree.py)

- `Node` 클래스에 값과 왼쪽·오른쪽·부모 노드 참조를 저장합니다.
- 재귀 삽입으로 이진 탐색 트리를 구성합니다.
- 최솟값에서 루트를 거쳐 최댓값으로 이어지는 경로와 간선 수를 출력합니다.

```sh
python examples/python/binary_search_tree.py
```

입력:

```text
8 3 10 1 6 14
```

출력:

```text
경로 : 1-3-8-10-14, 거리 : 4
```

현재 예제는 숫자 하나를 입력하면 거리 0을 출력하고, 중복값을 만나면 출력을 종료합니다.
빈 입력·숫자가 아닌 값의 처리와 편향된 트리에서 재귀가 깊어지는 상황을 개선점으로 기록합니다.
