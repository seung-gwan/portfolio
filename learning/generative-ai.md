# 생성형 AI — 조건부 DDPM 이모지 생성 실습

**PyTorch로 데이터 전처리, 조건부 이미지 생성 모델, 학습과 결과 기록 흐름을 공부했습니다.**

수업에서 제공된 모델을 바탕으로 한 학습 노트북과 저장된 결과를 정리한 기록입니다.

## 공부한 내용

| 단계 | 노트북에서 다룬 내용 |
| --- | --- |
| 데이터 구성 | 파일명의 감정 표현을 세 가지 조건 레이블에 연결하는 Dataset |
| 전처리 | 투명 이미지를 흰 배경에 합성하고 RGB로 변환 |
| 입력 변환 | 72×72 크기 조정, 좌우 반전, 정규화 |
| 모델 | CNN 블록과 U-Net, 시간·클래스 임베딩 |
| 학습 | 노이즈 예측을 학습하는 조건부 DDPM과 MSE loss |
| 기록 | epoch별 loss와 시간 CSV, 샘플 이미지, 모델 가중치 저장 |

## 남아 있는 결과

학교 폴더에는 학습 노트북, 생성 이미지, 모델 가중치와 `train_log.csv`가 보관되어 있습니다.
아래 수치는 그중 CSV 한 파일에 기록된 값을 기준으로 합니다.

원본 CSV에는 1,000개 epoch가 기록되어 있습니다. 위 표의 원래 수치는 [로그 발췌 CSV](../evidence/ai-training-log-excerpt.csv)에서 확인할 수 있습니다.

폴더의 노트북 출력과 별도 CSV에는 서로 다른 실행 수치가 남아 있어 하나의 실행으로 합쳐 설명하지 않았습니다.
학습 loss만으로 생성 이미지 품질이나 새로운 데이터에 대한 성능을 판단할 수는 없습니다.
이번 정리에서는 재학습을 수행하지 않았습니다.
