# 웹 기초 — HTML · CSS · JavaScript

**문서 구조를 만들고, 스타일과 레이아웃을 적용하고, 함수의 동작을 확인하는 예제를 공부했습니다.**

[Web_Lecture 저장소](https://github.com/seung-gwan/Web_Lecture)

| 학습 주제 | 저장된 예제 |
| --- | --- |
| HTML | 텍스트, 링크, 표, 영상 삽입, 입력 태그 |
| CSS 선택자 | 전체·태그·ID·클래스·속성·하위 선택자 |
| CSS 레이아웃 | float, overflow, margin, width를 활용한 배치 |
| JavaScript | 익명 함수와 반환값 실습 |

예제를 내려받아 HTML 파일을 브라우저에서 열어 확인하는 학습 구성입니다.
이 기록은 저장소 파일 구성을 기준으로 정리했으며, 각 화면의 브라우저 동작은 새로 검증하지 않았습니다.
기초 예제와 연결해서 볼 수 있는 작업으로 [Smart Farm](../projects/smart-farm.md)을 함께 정리했습니다.

다음 과제는 같은 레이아웃을 Flexbox·Grid로 다시 만들고, 작은 화면에서도 내용을 읽기 쉽게 조정하는 것입니다.

근거: [Web_Lecture의 예제 파일](https://github.com/seung-gwan/Web_Lecture).
