# 검증 기록

기준일: 2026-11-02

학교 실습의 원래 동작을 소개하기 위한 공개용 발췌본입니다. 프로젝트별 확인 범위를 아래에 기록합니다.

| 대상 | 확인 범위 |
| --- | --- |
| Java 계좌 예제 | JDK 25.0.3으로 컴파일 성공. Bank 실행 성공, Bob 잔액 5,000 → 7,000 → 4,000과 음수 입금·잔액 부족 분기 확인 |
| Java Swing 전화번호부 | JDK 25.0.3으로 컴파일 성공. GUI 화면과 버튼 조작은 새로 검증하지 않음 |
| Python 문자 변환 | `ABC`를 `BCD`로 변환하고 `BCD`를 `ABC`로 복원하는 예제 실행 성공 |
| Python 이진 탐색 트리 | `8 3 10 1 6 14` 입력에서 `1-3-8-10-14`, 거리 4 확인. 숫자 하나의 거리 0, 중복 입력 시 출력 종료 확인 |
| Unity | 6개 프로젝트의 코드·장면·설정과 제공된 중간·최종 시연 영상 확인. 역할은 제작자의 설명 반영. 새 에디터 실행·빌드 미수행 |
| Unreal Engine | 2개 프로젝트의 맵·블루프린트와 날짜별 과제·제작 화면·영상을 확인. 새 에디터 실행·패키징 미수행 |
| 생성형 AI | 노트북 코드와 저장된 CSV 확인. 재학습·생성 품질 평가 미수행 |
| Smart Farm | 기존 소스·README 확인. 실설비 연결과 전체 기능 테스트 미수행 |
| JSP 웹 프로젝트 | 기존 Controller·DAO·README 확인. 서버·DB 통합 실행 미수행 |
| 웹 기초 | 저장소 예제 파일 구성 확인. 개별 화면 동작 미검증 |

문서의 내부 파일 링크를 확인했고, AI 로그 발췌 7행은 원본 CSV와 일치합니다.
공개 파일에서 학번·개인 PC 경로·일반적인 인증 토큰 패턴이 검출되지 않았습니다.
