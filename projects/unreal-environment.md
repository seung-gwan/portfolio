# Unreal Engine — 환경 제작과 아포칼립스 구상

![마을 환경 제작](https://raw.githubusercontent.com/seung-gwan/game-dev-studies/main/media/unreal-village.png)

게임그래픽스 수업에서 실내 조명, 지형과 건물 배치, 마을·도시 환경을 공부한 기록입니다.
제출 화면과 영상, 기획 문서를 날짜가 확인되는 범위에서 묶었습니다.

## 아포칼립스 구상

초기에는 농장과 집을 방어하는 좀비 웨이브를 구상했습니다.
발표에서는 방어 구역을 잃을수록 적의 접근 방향이 늘어나는 PC용 디펜스/FPS 아이디어를 소개했습니다.
학습한 환경 제작 결과와 기획 아이디어를 구분해 [기획 기록](https://github.com/seung-gwan/game-dev-studies/blob/main/docs/unreal-apocalypse-design.md)에 정리했습니다.

[장면 영상](https://github.com/seung-gwan/game-dev-studies/releases/download/showcase-2026-06/unreal-apocalypse-2026-06-02.mp4) · [발표 영상](https://github.com/seung-gwan/game-dev-studies/releases/download/showcase-2026-06/unreal-apocalypse-2026-06-04.mp4)

외부 모델·텍스처 팩을 활용한 작업이며, 공개 맵에는 해당 리소스의 복원이 필요합니다.
맵을 새로 실행하거나 기획 기능 전체를 검증한 결과는 포함하지 않습니다.
