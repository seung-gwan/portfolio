- 사용한 기술과 개념
- 이 작업에서 확인하려던 점

- 사용자가 할 수 있는 동작
- 화면, 시연 영상 또는 코드 링크

- 개인 작업 / 팀 작업 / 수업 예제 기반 여부
- 팀 작업이라면 맡은 기능과 코드 범위
- 참고 자료와 사용한 외부 리소스

## 실행 방법

필요한 환경과 실제로 확인한 실행 순서를 적습니다.

## 문제와 해결 과정

어떤 상황에서 문제가 생겼고, 원인을 어떻게 확인했으며, 무엇을 바꿨는지 적습니다.
